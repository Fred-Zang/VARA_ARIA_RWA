# Frameworks publics de démonstration

`framework_rwa_FULL-sous-points.json` est volontairement vide dans ce dépôt public. Le framework réglementaire complet utilisé en production est confidentiel et n’est pas distribué.

`framework_rwa_EXAMPLE.json` contient uniquement des critères synthétiques. Il documente la structure JSON attendue et ne doit pas être utilisé pour prendre une décision réglementaire ou de conformité.
